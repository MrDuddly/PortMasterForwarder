# PortMasterForwarder (pt-BR)
**Seus jogos, bem organizados — agora direto no console.** Roda em **Tools** no Knulli e é controlado só pelos botões.

## Instalar
1. Baixe `PortMasterForwarder-<versão>-knulli.zip` em **Releases**.
2. Descompacte e copie a pasta **`roms`** para a partição **SHARE** do cartão (mesclar).
3. No console: *Menu → Game Settings → Update Gamelists*. O app aparece em **Tools**.

Opcional (versões do Minecraft MCPE): copie `roms/tools/PortMasterForwarder/extras/McpeLauncher.sh` para `roms/ports/`.

## Controles
Lista: **←/→** categoria · **A** editar · **X** nova categoria · **Y** preencher vazios · **START** menu. Jogo: **←/→** fonte · **A** buscar · **X** digitar · **Y** limpar · **B** voltar.
Pastas de categoria que você já criou (ex.: `portandroid`) são detectadas sozinhas. Depois de **START → APPLY**, se a categoria não aparecer, reinicie o sistema.
