# Building PortMasterForwarder.exe

The Windows executable is built with [PyInstaller](https://pyinstaller.org/) from `packaging/portmasterforwarder.spec`. PyInstaller cannot cross-compile, so build on **Windows**
(or let the GitHub Actions workflow do it).

## On Windows

```bat
packaging\build_exe.bat
```

The script installs `requirements-build.txt`, runs the tests, builds `dist\PortMasterForwarder.exe` and prints its SHA-256.
Manual equivalent:

```bat
py -3 -m pip install -r requirements-build.txt
py -3 -m unittest discover -s tests
py -3 -m PyInstaller --noconfirm --clean --distpath dist --workpath build packaging\portmasterforwarder.spec
dist\PortMasterForwarder.exe --self-test
```

`--self-test` opens no window; it checks that the bundled resources, Pillow and the rules are present and exits with code 0 when everything is fine.

## With GitHub Actions

`.github/workflows/release.yml` builds the executable on `windows-latest` for every tag that starts with `v` (and on manual dispatch), runs the self-test, creates
`PortMasterForwarder.exe.sha256` and attaches both files to the GitHub release. See [RELEASING.md](RELEASING.md).

## Notes

- The executable is a single file that unpacks itself to a temporary folder on start, which is why settings are stored in `%APPDATA%\PortMasterForwarder`.
- It is **not code-signed**: Windows SmartScreen may warn, and some antivirus products flag PyInstaller programs. Signing requires a certificate; contributions of a signing setup are welcome.
- Windows version information (name, version, license) is generated by the spec from `portmasterforwarder.__version__`.

## About the first release build
The very first `PortMasterForwarder.exe` was produced by running the same `packaging/portmasterforwarder.spec` with a Windows build of Python 3.11 under Wine
(it passed `--self-test` and opened the GUI there), not on a native Windows machine. Official releases should be built by the GitHub Actions workflow, which uses
a clean `windows-latest` runner and publishes a SHA-256 checksum.

## Knulli (gamepad) zip
`bash scripts/build_release.sh` (Linux/macOS/WSL/Git Bash) writes `dist/PortMasterForwarder-<version>-knulli.zip` and its SHA-256. The zip holds a `roms/` folder to copy onto the SHARE partition.
The release workflow builds it on Ubuntu next to the Windows executable.
